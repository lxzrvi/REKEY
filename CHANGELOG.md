# Changelog

## 0.1.0 — Foundation (remote verification pending)

### Added

- Kotlin/Compose Android application scaffold with pinned Gradle wrapper and version catalog.
- Edge-to-edge entry activity, safe-area handling and scrollable phone-first foundation screen.
- Monochrome light/dark Material 3 themes and centralized typography/shapes.
- Offline Poppins Thin, Regular, Medium and Bold with official source provenance and OFL.
- White provisional wordmark on black; black provisional key icon on white; adaptive launcher and Android 12+ splash resources.
- Explicitly temporary brand-font fallback pending licensed Holiday by Letterhend Studio.
- Native Compose reveal/reset animation with saved interaction state.
- Four JVM design-contract tests and four instrumented Compose UI tests.
- GitHub Actions build, unit-test, lint, unsigned release shrinking and emulator smoke pipeline.
- Branding, architecture, build and verification documentation.

### Not yet done

- Product brief, actual app features, navigation and data layer.
- Licensed Holiday font acquisition/integration and final identity approval.
- Production signing and store publication.
- First remote CI run and real-device runtime/performance verification.
